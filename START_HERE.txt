🚀 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

  ANDROID USERS:
  1. Visit your website in Chrome
  2. See "Install" prompt (automatic)
  3. Tap "Install"
  4. App appears in app drawer
  5. Opens like native app!

  iPhone USERS:
  1. Visit your website in Safari
  2. Tap Share button
  3. Select "Add to Home Screen"
  4. App appears on home screen
  5. Opens like native app!

⚡ QUICK START (TEST IN 2 MINUTES)
═══════════════════════════════════════════════════════════════════════════

  1. Start dev server:
     $ npm run dev

  2. On Android phone with Chrome:
     - Visit: http://localhost:5173 (or your IP)
     - Install prompt appears automatically
     - Tap "Install"

  3. On iPhone with Safari:
     - Visit: http://YOUR_IP:5173
     - Tap Share → Add to Home Screen

  4. Test offline mode:
     - DevTools (F12) → Application → Service Workers
     - Check "Offline" box
     - Close app and reopen
     - It still works!

⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

  INSTALL PROMPT NOT SHOWING?
  → Android: Wait 2-3 seconds after visiting
  → iOS: Use manual Share → Add to Home Screen
  → Check: manifest.json is linked in index.html

  ICONS NOT DISPLAYING?
  → Create 3 PNG files in public/Image/
  → Match exact file names in manifest.json
  → Use PNG format (no JPG/GIF)

  SERVICE WORKER NOT WORKING?
  → Clear cache: DevTools → Application → Storage → Clear All
  → Restart dev server
  → Hard refresh: Ctrl+Shift+R

  See PWA_SETUP.md for complete troubleshooting guide.
